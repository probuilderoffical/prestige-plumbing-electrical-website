# Prestige Plumbing & Electrical Services

A responsive static business website built for GitHub Pages. The structure is intentionally framework-free so it loads quickly and can later be converted into a custom WordPress theme.

## Local preview

Open `index.html` directly, or run a small static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Before launch

Replace the Facebook-only contact button with the official phone, WhatsApp, email and service-area details when provided.
